Инструмент sql_query выполняет SQL (PostgreSQL 19) над таблицами схемы habr_1097022, она уже стоит в search_path.
- Ссылки между таблицами — текстовые id и key. Колонки text[] — массивы id: ищи через `= ANY (колонка)` или `unnest(колонка)`.
- Коды (thesis, irony, disputed…) лежат текстом, без пространства имён.
- Для SQL пометки «RDF: …» в описании колонок можно не учитывать.
- Таблицы и число строк в них: {{inventory}}.
