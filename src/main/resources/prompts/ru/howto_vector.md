Инструмент semantic_search ищет по смыслу: считает вектор текста query той же моделью, что и векторы text_embeddings (EmbeddingGemma), и возвращает k текстов статей, ближайших к нему, с косинусным расстоянием distance.
- Пиши query по-русски, своими словами, как описала бы искомое LLM в кратком содержании или выводе статьи; операторы поиска не нужны.
- Поиск всегда возвращает k ближайших текстов, даже если подходящих в памяти нет: проверь, что найденное отвечает на вопрос.
- where — условие SQL над колонками text_embeddings без слова WHERE: `embedding_name = 'summary'`, `primary_genre = 'opinion' AND published >= '2023-06-01'`, `nsfw`. Условия на колонки text, integer, boolean и date выполняются до поиска, условие на массив hubs — после него, поэтому строк может прийти меньше k.
- Одна статья может найтись несколько раз, разными текстами: embedding_name и index показывают, каким. habr_id и title — статья, к которой относится текст.
